# Подготовка — структура проекта

Открывать нужно `index.html` (все файлы лежат рядом, интернет нужен только для шрифтов).

```
index.html          разметка страниц
css/style.css       стили, в конце — мобильная версия (@media)
data/config.js      ★ настройки: RESULTS_ENDPOINT, TEACHERS, TEACHER_CODE_HASH, EXAM_MS
data/answers.js     ★ ответы вариантов (в виде хешей)
data/translations.js, theory.js, formulas.js, lessons.js   тексты и учебный материал
js/utils.js         хеширование, проверка ответов, экранирование HTML, окна uiAlert/uiConfirm, тосты
js/app.js           навигация, вход ученика, язык, отправка результата
js/quiz.js          экзамен: вопросы, проверка, таймер, итог, сохранение прогресса, защита от выхода
js/teacher.js       кабинет учителя
telegram-worker.js  прокси для уведомлений в Telegram (по желанию)
```

Сменить код учителя: в консоли браузера выполнить `teacherCodeHash('новый_код')`
и вставить результат в `TEACHER_CODE_HASH` (data/config.js).

Как вводить ответы: десятичные числа с точкой (`3.375`), несколько ответов через `;` (`3;1/28`).
Ученик может писать с пробелами, с запятой вместо точки и в любом регистре — это засчитывается.
