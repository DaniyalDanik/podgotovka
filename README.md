# Подготовка — структура проекта

Сайт: https://daniyaldanik.github.io/podgotovka/ — открывать `index.html` (все файлы лежат рядом, интернет нужен только для шрифтов).

```
index.html          разметка страниц
css/style.css       стили, в конце — мобильная версия (@media)
data/config.js      ★ настройки: RESULTS_ENDPOINT, TEACHERS, TEACHER_CODE_HASH, EXAM_MS, ANTI_CHEAT
data/answers.js     ★ ответы встроенных вариантов (в виде хешей)
data/translations.js, theory.js, formulas.js, lessons.js   тексты (RU/KZ) и учебный материал
js/utils.js         хеширование, проверка ответов, экранирование HTML, окна uiAlert/uiConfirm, тосты
js/app.js           навигация, вход ученика, язык, отправка результата и уведомлений
js/lessons.js       ответы к урокам и их проверка
js/quiz.js          экзамен: вопросы, проверка, таймер, итог, сохранение прогресса
js/anticheat.js     строгий режим: полный экран, учёт выходов со вкладки, запрет копирования
js/teacher.js       кабинет учителя: результаты, выгрузка в Excel, редактор вариантов
telegram-worker.js  прокси для уведомлений учителю в Telegram (по желанию)
```

## Возможности

- **Уроки** по 15 темам с проверкой ответов. Ответ засчитывается в любой разумной записи:
  `x²+2x+1` = `x^2+2x+1`, `10^4` = `1×10^4`, `0.5` = `1/2`, `2.666` ≈ `2.67`, корни в любом порядке.
- **Экзамен**: таймер, одна попытка на вопрос, прогресс сохраняется при перезагрузке.
- **Строгий режим экзамена**: полный экран; уход на другую вкладку, в другое приложение, выход из полного
  экрана, перезагрузка — засчитываются как «выход». Ученик видит предупреждение и счётчик, учитель видит
  число выходов в таблице. После N выходов экзамен завершается автоматически. Копирование и печать отключены.
- **Кабинет учителя**: результаты, фильтры, выгрузка в Excel (CSV), свои варианты:
  текстовые вопросы и/или картинки, варианты ответа A–E с текстом или открытый ответ, любое число вопросов (1–40),
  своё время и настройки строгого режима; варианты можно просматривать и редактировать.
- **Уведомления в Telegram** (если настроен `telegram-worker.js`): ученик начал экзамен, ученик вышел со вкладки, итог.
- Интерфейс на русском и казахском.

## Настройка

Сменить код учителя: в консоли браузера выполнить `teacherCodeHash('новый_код')`
и вставить результат в `TEACHER_CODE_HASH` (data/config.js).

Уведомления в Telegram: создать Worker из `telegram-worker.js` (инструкция в начале файла)
и вставить его адрес в `RESULTS_ENDPOINT` (data/config.js).

Как вводить ответы в варианты: десятичные числа с точкой (`3.375`), несколько ответов через `;` (`3;1/28`).
Ученик может писать с пробелами, с запятой вместо точки и в любом регистре — это засчитывается.

## Ограничения

Результаты и авторские варианты хранятся в браузере (`localStorage`). Учитель видит в кабинете результаты,
сданные на этом же устройстве; с других устройств результаты приходят в Telegram.
Браузер не позволяет полностью запретить уйти со страницы — строгий режим фиксирует выходы и сообщает о них.
